# Debug: motion-not-playing

状态：[OPEN]

## 现象
用户反馈局部动态明信片“没有动”。

## 假设
1. AI 返回空区域。
2. 动态层尺寸为 0 或超出容器。
3. 动画层处于暂停状态。
4. CSS 动画存在但视觉变化不明显。
5. 当前展示数据没有 animations 元数据。

## 证据
- 用户确认模型返回了区域且动画能够播放，排除“空区域”和“动画未执行”。
- 用户反馈实际运动部位不正确，问题定位为视觉模型输出的框选范围过宽或中心偏移。
- 前端使用原图归一化中心坐标并按 object-fit: cover 换算，坐标语义与提示定义一致。

## 修复
- 强制模型仅输出实际运动物体的紧致外接框。
- 轮子要求中心贴合轮心；擦拭动作仅框手臂或抹布，不框整个人。
- 推荐区域数量由 1-5 收紧为 1-3，并将区域尺寸上限由 0.45 收紧到 0.30。

## 待验证
重启服务后对同一图片重新执行 AI 动效分析，确认部位是否更准确。
