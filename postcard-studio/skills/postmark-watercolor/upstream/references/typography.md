# typography · 目的地本地语言排版 + 面值取值

> 邮票新增文字只使用五种目的地语言包（`zh` / `en` / `ja` / `fr` / `ko`）；其他目的地统一回退英文，不跟随用户输入语言。原则：**已选语言包为主、中文是否中英混排由题材决定、辅助行不重复、层级清晰**——既保留目的地感，也降低生图文字出错率。

## 支持语言与回退（locale-aware，优先于其他排版规则）

目的地新增文字只支持五个 locale：`zh`（中文）、`en`（英文）、`ja`（日文）、`fr`（法文）、`ko`（韩文）。先根据**目的地**确定 `$DISPLAY_LANGUAGE`，再生成 `$COUNTRY_PRIMARY`、`$CITY_PRIMARY`、tagline 和 `$POSTMARK_PLACE`；用户输入语言只用于理解地点与文件/文件夹命名，不决定这个 locale。

| `$DISPLAY_LANGUAGE` | 主文字 | 可选辅助行 | 约束 |
|---|---|---|---|
| `zh` | 中文（目的地官方/常用字形） | 较小标准英文名或拼音 | 现代城市/街拍默认加入；古建筑/遗址/传统文化题材默认省略 |
| `en` | 英文 | 无 | 只显示一套英文；不要再放同义的罗马字、中文或第二行英文 |
| `ja` | 日文（汉字/假名） | 较小标准罗马字或英文 | 日文优先；辅助行不是中文翻译，且必须更轻更小 |
| `fr` | 法文（保留重音与法文大小写） | 通常无 | 法文为唯一主语言；不因用户输入中文而添加中文或英文重复行 |
| `ko` | 韩文（Hangul） | 较小标准罗马字或英文 | 韩文优先；辅助行不是中文翻译，且必须更轻更小 |

目的地语言不在上述五种时，统一将 `$DISPLAY_LANGUAGE` 设为 `en`，并在来源/说明中注明这是英文回退：所有**新增**国名、地名、标语和邮戳均用英文，不复制用户输入，也不添加中文。多官方语言地区按地点所在区域选择上述 locale；无法可靠判断且会改变可见文字时询问用户。这里约束的是**新增邮票文字**；参考照片原有招牌、品牌标识、路牌和建筑铭牌继续按 source text preserve 规则保留，不翻译、不删除。

### 中文目的地的题材化中英混排

`$DISPLAY_LANGUAGE=zh` 时，英文 secondary 不是固定必填项，而是由照片主体决定：

- **默认加入英文 secondary**：现代城市全景、街拍、夜景、交通、商业街、当代建筑和城市生活。使用可靠的标准英文短名；没有通行英文名时才用规范汉语拼音。
- **默认省略英文 secondary**：古建筑、遗址、石窟、寺庙、宗教建筑、传统园林、文物和以传统文化为主体的画面。即使拍摄地位于现代城市，也以主体类别为准。
- **其他中国自然风景**：默认只用中文；只有目的地本身以国际旅行语境呈现、用户要求，或英文名能明显改善识别时才加入。
- 用户明确要求中英混排或纯中文时，覆盖自动判断。

加入时，`$CITY_SECONDARY` 放在完整中文主标题正下方，与其共用同一轴线；英文高度约为中文主标题的 `30–40%`，字重更轻、字距更疏，不与中文争夺第一层级。中英混排属于 `zh` 语言包内部的辅助层，不改变国名、邮戳和 tagline 的中文主语言。

## 层级（从大到小）

| 位置 | 内容 | 字号 | 说明 |
|------|------|------|------|
| 顶部国名条 | `<COUNTRY_PRIMARY>` + 可选 secondary | 小 | 本地国名为主，辅助行仅在不同且必要时出现 |
| 底部主标题 | `<CITY_PRIMARY>` | **最大** | 目的地本地地名，最显眼 |
| 主标题副 | `<CITY_SECONDARY>` | 小/中 | 仅按 locale 与题材规则加入；约为主标题高度 30–40%，与主标题相同则删除 |
| tagline | 本地语言 + 按 locale 允许的 secondary | 小 | 本地化、简短、自然（可选） |
| 角落 | `<面值>` | 小 | 辅助层级，角落；不得与国名或主标题争抢视觉焦点 |
| 邮戳 | `<POSTMARK_PLACE> + 日期` | 小/淡/残缺 | 使用目的地 locale；结构精致但油墨不完整，不得像粗重完整的徽章（$POSTMARK=yes 时） |

## 对齐轴线（先定网格，再定位置）

- 把 `<CITY_PRIMARY>` 与可选 `<CITY_SECONDARY>` 当作一个标题组。居中时两行共用完全相同的中心轴；左对齐时两行共用完全相同的左边缘；辅助行必须位于完整主标题正下方。
- 不使用 `near the title`、`beside the title` 等模糊位置词。辅助行不得只对齐主标题的首字、末字或某个局部，也不得自行漂到标题左下角。
- 国家名是独立页眉：按风格明确锚定内框左边缘或内框中心轴。它可以与标题组形成有意的双轴结构，但不能再引入第三条浮动轴线。
- `hero-overlay` 默认采用“内框锚定的国家页眉 + 负空间光学居中的双语标题组”；`bottom-band` 与 `framed-label` 则让主副标题在同一信息块/容器内共轴。
- 面值、邮戳和微型信息分别锚定内框角点或同一容器边缘；不靠“哪里空放哪里”形成偶然对齐。

## 跨 locale 排版要点（写进 prompt 的 `$TYPE`）

- **所有文字尽量短**：`zh/ja/ko` 的 tagline 尽量 ≤10 个字形，`en/fr` 和英文回退的 Latin 文本尽量 ≤40 个字符。越长越易生成错误或拥挤。
- **国名用短形**：按 `$DISPLAY_LANGUAGE` 采用当地常用短名；不要把用户输入的中文、原文全称或重复的英文塞进辅助行。默认短形。
- **标题组对齐**：主语言与可选辅助行共用中心轴或左边缘，辅助行更轻、更小；`ja/ko` 的罗马字与 `zh` 的英文辅助行始终低于主标题的视觉层级。中文城市英文 secondary 高度约为主标题的 `30–40%`。
- **字体配对**（按风格，见各 `styles/*.md` 的 `$TYPE`）：
  - 现代无衬线风格（risograph）→ 各脚本使用同一几何或粗体气质的无衬线；`zh` 用黑体，`ja` 用 Gothic，`ko` 用 Gothic，`en/fr` 与英文回退用 Helvetica/Futura 风。
  - 衬线风格（watercolor / vintage / classic / engraved）→ 各脚本使用同一正式衬线气质；`zh` 用宋体/楷书，`ja` 用明朝体，`ko` 用 명조（Myeongjo），`en/fr` 与英文回退用 Garamond/Caslon/Century 风。
  - 木刻风格（woodblock）→ 保留刻痕审美；Latin locale 可用大写，`zh/ja/ko` 改用对应脚本的直立展示字形和字距，不强行套用大小写。
- **字距**：国名/副标题加 letter-spacing 显精致；主标题紧凑。

## 长文字处理（灵活，别死板居中）

默认**居中对齐**（邮票正式感）。但文字偏长时硬居中会挤、会溢出，要灵活：

- **判断阈值**：`zh/ja/ko` tagline > 12 个字形、`en/fr` 或英文回退 > 50 个字符 = 偏长；前者 > 18 个字形、后者 > 80 个字符 = 太长，强烈建议缩短。
- **偏长**：可改**左对齐**（left-aligned，贴左边距留呼吸感），或缩小一号字号、分两行居中。
- **太长**：**主动给用户一个缩短建议**（给 1–2 个缩短版方案让其选，见 `workflow.md` Step 1），用户坚持再用长版（左对齐 + 小字号 + 必要时砍 secondary tagline）。
- **城市名/国名**：一般短，不涉及；若城市名超长，按 locale 使用当地短形（`zh/ja/ko` 不切换成中文或英文，`en/fr` 维持 Latin 短名）。
- **对齐 × 风格**：classic/vintage/engraved 偏正式 → 优先居中；risograph 现代可左对齐；watercolor 随性可左对齐配手写感；woodblock 依刻版构图选择居中或对称轴。

> 核心原则：文字服务可读性和精致度，不为「必须居中」牺牲。长文字先建议缩短，其次换对齐/字号，绝不硬塞到溢出。对应 prompt 模板的 `$ALIGN`（默认 `centered`）。

## 主题字体（按主体/氛围匹配，喂给 prompt 的 `$TITLE_FONT`）

> **看氛围不只是看地域**：现代人像 / 时尚 / 现代都市 -> 现代无衬线（思源黑/Helvetica），**不用楷书**；传统 / 历史 / 古典 / 文化题材才用楷书/古典衬线。

主标题字体**按照片主体/地域**选，不是通用宋体。识图（vl）后定（见 `workflow.md` Step 1）：

| 主题/地域 | `$TITLE_FONT`（写进 prompt 描述） |
|-----------|--------------------------------|
| 现代人像 / 时尚 / 现代都市 | 现代无衬线（思源黑体 / Helvetica / Futura），不用楷书 |
| 敦煌/莫高窟/佛教/石窟/丝路/古迹 | 北魏写经体/魏楷，毛笔书法，沉雄历史质感（参汉仪「敦煌当代魏楷」，《成实论》写经风） |
| 中国其他古迹/古镇/山水/民俗 | 楷书/行楷，毛笔书法感 |
| `ja` 目的地 | 明朝体（Mincho）+ 毛笔，和风 |
| `ko` 目的地 | 명조（Myeongjo）+ 韩文笔触 |
| 现代/国际都市 | 几何无衬线（Helvetica/Futura 风） |
| 欧美经典/复古 | 衬线（Garamond/Caslon）或 Art Deco 字母 |
| 中东/伊斯兰 | 几何库法构成启发的拉丁展示体；显示串仍按 `en` fallback，不新增阿拉伯字母 |
| 人物/肖像纪念 | 按人物地域：中国 -> 楷书/行楷，西方 -> 古典衬线（engraved nameplate 感） |
| 不确定/默认 | 清晰衬线或无衬线（随风格 `$TYPE`） |

> prompt 写法例：`Title "莫高窟" rendered in Dunhuang sutra-copying script (写经体 / 魏楷), brush-pen calligraphy with the dignified historical texture of Northern Wei manuscripts`。

## 弧形/环绕排版（不全平铺，喂给 prompt 的 `$TEXT_PATH`）

邮票经典做法，文字不必全平铺直线：

- **顶部国名**：默认沿**顶部弧线**排列（curve along the top perforated edge）--经典邮票语言。
- **邮戳**：圆形环绕（circular, text around the ring）；地名沿上弧，日期使用更小的窄体数字置于中心或下弧，结构清楚但油墨只保留约 45–60%。
- **底部主标题**：默认直排居中；vintage/woodblock 等风格可走**底部弧线**呼应顶部。
- **面值**：角落，直排小字。
- 短文字优先走弧线显精致；长文字仍走直线（见长文字处理）。

> prompt 写法例：`Country name "<COUNTRY_PRIMARY>" set along a gentle arc following the top perforated edge; use only the destination locale and omit any user-language translation`。

## 面值 `$DENOM` 取值（按国家货币自动）

### 面值视觉尺度

面值只是识别邮票属性的辅助信息，不是海报数字：

- 整个面值块宽度默认不超过内框宽度约 `15%`，字符高度约为主标题高度的 `30–45%`；不得大于国名页眉，也不得成为画面第二标题。
- 货币符号或单位（如 `元` / `円` / `€`）可缩到主数字的 `60–70%`，使用同一基线、上标或紧凑小单位处理。
- `FOREVER` / `1st` / `P` 等文字型面值按小号邮政标签处理，不放大成标题。
- 面值始终锚定内框角点，周围保留稳定安全区；空间不足时先缩小面值，不挤压国家名、标题组或坐标微字。

用户没指定时，按下表取一个常见面值；国家不在表里 → 用该国货币符号 + 一个整数（如 `£1` / `₩100` / `฿5`）；实在不确定 → 用通用 `★` 或省略面值（prompt 删掉 denomination 行）。

| 国家 | 国名（短） | `$DENOM` 候选 |
|------|-----------|--------------|
| 中国 | 中国 / CHINA | `1.20元` 或 `8元` |
| 日本 | 日本 / JAPAN | `110円`（默认；本地化且不与人民币符号混淆） |
| 韩国 | 韩国 / KOREA | `₩330` |
| 美国 | USA / U.S.A. | `FOREVER` 或 `55¢` |
| 英国 | UK / GREAT BRITAIN | `£1.00` 或 `1st` |
| 法国 | FRANCE | `€1.10` 或 `€0.80` |
| 德国 | GERMANY（`en` fallback） | `€0.80` |
| 意大利 | ITALY（`en` fallback） | `€1.10` |
| 西班牙 | SPAIN（`en` fallback） | `€0.80` |
| 澳大利亚 | AUSTRALIA | `$1.10` |
| 加拿大 | CANADA | `P`（Permanent）或 `92¢` |
| 瑞士 | SWITZERLAND（默认 `en` fallback；法语区可用 `fr`） | `1.00` 或 `CHF 1` |
| 泰国 | THAILAND | `฿5` |
| 印度 | INDIA | `₹5` |
| 俄罗斯 | RUSSIA（`en` fallback） | `₽10` |
| 埃及 | EGYPT | `E£ 1` |

> 注：面值只是邮票「真实感」的装饰细节，不必精确到真实邮资，合理即可。
>
> 日本虽也使用 `¥` 表示 JPY，但该符号与人民币共用，在中文语境容易产生歧义。除非用户明确指定，统一使用带 `円` 的本地化面值（默认 `110円`）。
