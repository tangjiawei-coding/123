# qa-checklist · 质检清单

> 一次性生图，**本地语言文字是头号翻车点**。本地原图在生成前先用 `view_image` 查看；生成后**必看**：用 `view_image` 打开 `<style>-<location-name>.png` 做全图视觉验收，必要时用系统图像工具核对尺寸/裁切。Codex 原生 `imagegen` 不提供 `quality`、`resolution`、`ar` 等独立参数；把方向与比例写进 prompt，并按实际输出验收。任一必查项不通过就重试（最多 2 次），每次只做一个针对性修正，不得把失败图当成品交付。

## 1. 目的地语言与场景文字

- [ ] **语言包只取 `zh` / `en` / `ja` / `fr` / `ko`**：目的地属于其他语言时，新增邮票文字统一回退英语；不得临时创造第六种语言包。
- [ ] **新增文字使用目的地语言**：逐字核对 `$COUNTRY_PRIMARY` / `$CITY_PRIMARY` / `$TAGLINE_PRIMARY` / `$POSTMARK_PLACE` 及实际启用的 secondary。中国目的地中文为主；日本主标题为日文；英语目的地只用英语（例如伦敦为 `LONDON`）。
- [ ] **中文 secondary 符合题材**：现代城市、街拍、交通、夜景、商业街和当代建筑默认有较小标准英文地名；古建筑、遗址、石窟、寺庙、宗教建筑、传统园林、文物和传统文化主体默认不加英文。主体类别优先于所在城市；用户明确要求时例外。
- [ ] **不受用户输入语言污染**：外国目的地不得因为用户用中文输入而自动新增中文标题、标语、国名翻译或邮戳文字；日/韩可按约定附较小英文/标准罗马字，但不得附中文翻译。
- [ ] **辅助行正确且不重复**：secondary 仅在非空、与 primary 不同且确有需要时出现；英语目的地不得重复同一英文标题。
- [ ] **精确字符串**：新增标签必须与实际 prompt/`_source.md` 中的 EXACT TEXT 逐字符一致，无错字、替换、镜像、反字、伪文字或额外字符。邮戳是物理缺墨例外：检查其原始内容无错误字符，但允许正确字符的部分笔画不可见。
- [ ] **无模型凭空新增文字**：除指定邮票文字、指定邮戳与参考图原有文字/标识外，不出现额外字母、汉字、乱码、水印、签名、徽标或装饰性伪文字。
- [ ] **参考图原有文字/标识默认保留**：逐项核对显著店招、品牌标识、路牌、建筑铭牌仍在且尽量忠实；不要把这些 source-scene 文字误判成模型新增文字。只有用户明确选择简化、模糊或移除时，才接受对应变化。

## 2. 信息密度与事实来源

- [ ] **密度值合法且符合选项**：`$INFO_DENSITY` 只能是 `minimal` / `standard` / `archival`，且一张票只按选定密度启用模块，不为“填满”而堆信息。
  - `minimal`：国名、地名、面值、可选邮戳；tagline 至多一行。
  - `standard`：包含 minimal；可加设计年份与国家代码/装饰序号，再从坐标、别称、航邮标签中至多选 1 项；有可信具体地点坐标时优先坐标，背景繁忙时可以更少，事实型内容必须有可靠来源。
  - `archival`：包含 standard；版面允许且来源可靠时再加建成年份、坐标、别称、短 motto 等，微型模块总数不超过 4 个。
- [ ] **事实可追溯**：`$COORDINATES` 只能来自照片 EXIF GPS、用户提供的准确位置或可靠核验的具体地标/拍摄点；只有城市名时不得使用城市中心坐标冒充拍摄点。`$ESTABLISHED_YEAR`、`$PLACE_EPITHET`、地方 motto 等只能来自用户或可靠核验。按顺序检查 `_source.md` 的 `EXIF` / `user-provided` / `verified` 记录。
- [ ] **坐标格式与尺度**：启用时默认使用单行十进制度四位格式，如 `39.8822°N · 116.4066°E`；约为国家名高度的 55–70%，100% 可读但缩略图不抢视觉，并与 `_source.md` 来源一致。
- [ ] **缺数据就省略**：没有来源或无法核验的坐标、建立年份、别称、motto、国家代码等从画面、布局和 EXACT TEXT 中整段删除，不用伪文字或猜测补位。
- [ ] **年份和序号不冒充官方**：`$ISSUE_YEAR` 只能表示本次纪念设计年份；`$SERIAL` 只能作为视觉序号，并在 `_source.md` 明确标记 `decorative / non-official`，不得暗示真实邮政发行、限量、认证或官方编号。
- [ ] **不虚构**：除上述可追溯信息与用户明确提供的内容外，没有虚构地标史实、徽章、机构、邮政发行信息或地域口号。

## 3. 标题模式与场景适配

- [ ] **只选一个标题模式**：`$TITLE_MODE` 只能是 `bottom-band` / `hero-overlay` / `framed-label`；三者按场景选择的替代方案，**不是每个模板都强制使用，也不是每张票都必须有大标题**。
- [ ] **`hero-overlay` 条件成立才使用**：画面有干净负空间、标题较短、且存在适合的主体/前景关系；前景遮挡标题面积约 `10–20%`，标题关键字母/汉字轮廓仍可辨认；不为制造景深凭空添加错误地标。
- [ ] **复杂背景优先 `framed-label`**：街景、建筑群、纹理繁复或原图已有多处文字时，标题应放入有地域/风格依据的 cartouche、铭牌、绶带或几何框，不能把大标题硬压在背景上。
- [ ] **长标题/克制风格优先 `bottom-band`**：标题或 tagline 偏长、负空间不足、自然风景/水彩或需要稳定留白时，使用独立底部信息带；长文案可左对齐、缩字号或分行，不能挤出框。
- [ ] **版式层级清楚**：主图、顶部国名、底部标题/tagline、面值和邮戳各有层级；中英/罗马字基线对齐，辅助行小而轻，不与主标题争夺第一视觉层级。中文城市英文 secondary 约为中文标题高度的 30–40%。横版保持宽幅主图；若选择 `bottom-band`，信息带应横向铺开，不把横景挤成竖构图。
- [ ] **对齐轴线成立**：国家名明确锚定内框左边缘或中心轴；主地名与 secondary 组成同一标题组，严格共用中心轴或左边缘。辅助行必须位于完整主标题正下方，不得悬浮在单个字的左下角，也不得形成第三条偶然轴线。

## 4. 可读性与装饰

- [ ] **标题对比度足够**：主标题与承载背景有明确明暗反差，目标相当于约 `4.5:1`；缩略图可读，且 100% 查看字形边缘清楚、无断笔/糊字。
- [ ] **微字有承载结构**：坐标、年份、序号、邮政标签、邮戳文字不直接压在高频纹理上；使用纸色/半实底、标题牌、细描边或 keyline，并在 100% 查看仍可辨认。
- [ ] **面值克制**：整个面值块宽度不超过内框约 15%，字高约为主标题 30–45%，且不大于国家名页眉；币种符号/单位可为数字高度 60–70%。面值不得成为第二标题。
- [ ] **无溢出、拥挤、截断**：tagline 和微字不出框、不互相覆盖；偏长文本改左对齐、缩字号或缩短，不硬塞居中。
- [ ] **装饰克制且有依据**：装饰容器、花边、角花、徽记与目的地/所选风格相关，优先抽象当地建筑几何、植物、织物、瓷砖、航海或邮政符号；不过度抢文字与主体层级，不在每张票套同一套欧式花边，不复制其他城市专属徽章/纹样。
- [ ] **全票材质真实且中性**：默认 `subtle` 时，纸纤维、轻微墨色浓淡变化与齿孔/边框微磨损应贯穿整张邮票及主体插画，不只存在于外框；保持模板原配色，不自动泛黄、棕褐化、脏污或重度做旧。
- [ ] **邮戳结构精致且像二次盖印**：直径约为邮票短边 18–24%；细外环 + 局部细内环、上弧地名与更小日期层级清楚，可选 2–4 条细 killer bars；约 45–60% 可见完整度、有效墨色约为主体深墨 25–45%，存在自然断线、缺墨、压力不均、轻微渗化或偏转。不得带无依据星章/盾徽，不得呈现为全不透明、完整闭合、等粗且极清晰的矢量徽章或粗糙大橡皮章。
- [ ] **印刷质感不伤关键文字**：投影、纸纹、网点与套印错位不能破坏标题、面值和信息模块识别；邮戳可自然残缺，但可见字符不得错误。

## 5. 邮票元素、方向与几何

- [ ] **邮票元素齐全**：齿孔边（perforated border）+ 顶部国名 + 角落面值 +（`$POSTMARK=yes` 时）邮戳；`$POSTMARK=no` 时不得凭空新增邮戳。
- [ ] **方向跟随参考图**：横图→横票（`landscape` / `4:3`），竖图→竖票（`portrait` / `3:4`），方图→方票（`square` / `1:1`，参考图宽高比 `0.9–1.1`）；用户未明确覆盖时不得改变方向。横图须保留宽幅主图，不得挤成竖构图。
- [ ] **四边画布间距统一**：以邮票最外侧齿孔与阴影为边界，到画布上/右/下/左的净距均约为画布短边 `4%`，任意两边偏差不超过短边 `1%`；无贴边、裁切、倾斜、偏心或阴影越过安全区。
- [ ] **主图主体认得出**：地标轮廓、关键特征和参考场景主体仍在（参考图引导应尽量保留）；人脸可有合理偏差，但不得损伤关键地标识别。
- [ ] **风格到位**：只从 6 款核心风格中验收——classic 规范平衡、watercolor 水彩晕染、vintage 做旧褪色、risograph 网点与套印、woodblock 刻痕与手工压印、engraved 精细凹版线刻；整体像真邮票（印刷感、纸感、微投影），不像随意贴字。

## 6. 交付文件

- [ ] **精确文件命名与路径**：用户输入中文地点时，文件夹与图片文件名都保留中文地点（如 `20260804-夏塔/watercolor-夏塔.png`），不得转拼音或英文；无中文地点时才使用英文小写 kebab-case。
- [ ] **成品文件唯一且无临时后缀**：正式成品优先为 `<style>-<location-name>.png`；同名旧图已存在时允许 `<style>-<location-name>-v2.png` 等安全版本后缀。不得交付 `stamp.png`、缺失地点、只有风格或 `-rN` 重试后缀。
- [ ] **来源记录同步**：`_source.md` 记录实际语言包、标题模式、信息密度、启用模块及来源（`EXIF` / `user-provided` / `verified` / `decorative`），并与成品可见内容一致。

## 看不清怎么办

- `view_image` 先按全图检查；需要放大细节时，直接用系统图像工具查看/裁切文字区（顶部国名条 / 标题容器 / 底部标题区 / 邮戳），并在 100% 查看原图。
- 若图像尺寸或裁切无法确认，用系统图像工具读取实际像素和边界；以实际输出验收，不依赖生成参数。
- 原生 `imagegen` 不提供单独的质量、分辨率或宽高比参数；修正方向/比例时，只在 prompt 中明确 `landscape / 4:3`、`portrait / 3:4` 或 `square / 1:1`，再按输出检查。

## 不通过 → 重试（最多 2 次）

| 问题 | prompt 调整 |
|------|-----------|
| 中文错别字/多笔/反字 | TEXT 段前加 `The text must be perfectly legible and correct — this is the most important requirement.`；**缩短中文**（tagline 砍到 ≤6 字，或去掉 tagline 只留城市名）；把出错的字单独再强调一次 |
| 英文或其他目的地语言拼错 | 同上强化；重新确认 `$DISPLAY_LANGUAGE` 只取 `zh/en/ja/fr/ko`；把出错单词/字符单独列出 |
| 目的地语言错误/国外出现中文标题 | 重新确定目的地语言包与全部本地化显示串；强调 `use destination-local language, not the user's input language`；不支持的目的地语言明确回退英语；删除中文新增文字后重试 |
| 中国题材中英混排不合适 | 重新判定主体：现代城市/街拍/交通/夜景/商业街/当代建筑补小号标准英文 secondary；古建筑/遗址/石窟/寺庙/传统文化主体删除英文 secondary；用户明确要求优先 |
| primary/secondary 重复或出现空行 | 从布局说明和 EXACT TEXT 列表中删除 secondary/空变量，不要只写 omit 指令后仍保留字符串 |
| 冒出模型新增的多余文字 | 强调 `Do not invent additional design typography or pseudo-text.`；不得用“只允许指定串”误删参考照片原有店招/标识 |
| 参考图原有招牌/标识缺失或被擅改 | 强化 `preserve the existing source-scene sign/logo faithfully`；若模型难以还原或判断会影响版式，暂停重试并先询问用户如何处理 |
| 信息模块无来源、数据被虚构或序号像官方编号 | 从 prompt/EXACT TEXT 中删除无法由 EXIF、用户或可靠核验支持的模块；将 `$SERIAL` 标成 `decorative / non-official`；不要把 `$ISSUE_YEAR` 写成真实发行声明 |
| 坐标缺失、过大或来源不准确 | 有 EXIF/用户准确位置/已核验具体地点时，用十进制度四位单行微字补入；只有城市名时删除坐标，不用城市中心冒充；缩到国家名高度 55–70% 并加安静底板 |
| 标题模式与场景不合/hero-overlay 遮挡过多 | 重新按场景三选一：复杂背景改 `framed-label`，长标题/克制风格改 `bottom-band`；`hero-overlay` 仅保留干净负空间并把遮挡控制在 10–20%，关键字保持可读 |
| 国家名、主标题与 secondary 对齐混乱 | 写出明确锚点：国家名对齐内框；primary/secondary 作为一个标题组共用中心轴或左边缘；删除 `near the title` 等含糊位置词 |
| 标题/微字对比不足、底板或装饰过重 | 增加纸色底板、半实底、描边或 keyline；减弱纹理/投影/花边，保持地域与风格相关且不抢文字层级 |
| 全票过于数码光滑或被错误泛黄 | 设 `$PRINT_MATERIALITY=subtle`：仅增加中性纸纤维、墨色轻微起伏和边缘微磨损；明确禁止黄色/棕褐滤镜、污渍和重度做旧 |
| 邮戳像锐利完整徽章 | 强调 cancellation overprint：直径为短边 18–24%，只保留 45–60% 可见油墨与主体深墨 25–45% 的有效深度，加入断环、缺墨、干印章颗粒、轻微渗化与 3–7° 偏转；不要再要求邮戳每个笔画完全清楚 |
| 面值太大/像第二标题 | 把整个面值块压到内框宽度 ≤15%、主标题高度 30–45%，且不大于国名；单位缩到数字高度 60–70%，继续锚定角点 |
| 邮戳粗糙或不够精致 | 控制直径为短边 18–24%，改成细外环 + 局部细内环、上弧地名、小号日期和可选细 killer bars；删除星章/盾徽/花边，油墨降到 45–60% 可见、主体深墨 25–45% |
| 邮票元素缺失 | 强化 FRAME 段对应元素（如 `denomination MUST appear in one corner`、`perforated border on all four sides`）；`$POSTMARK=no` 时删除邮戳要求 |
| 风格不像 | 强化 `$STYLE_ART` 关键词，减少冲突描述；保留对应地域/风格装饰，不套无依据花边 |
| 主图不像原图主体 | 使用参考图时加 `closely follow the reference photo's subject, composition, and key landmarks` |
| 方向与参考图不一致 | 修正 `$ORIENTATION` 及 prompt 中的方向/比例说明：横图 `landscape/4:3`、竖图 `portrait/3:4`、近方图 `square/1:1`；禁止复用固定 `3:4` |
| 四边间距不一致/贴边 | 强化 `CANVAS GEOMETRY`：邮票整体居中，外缘含阴影距四边均为短边 4%，四边偏差 ≤1%，无裁切；重试后重新测 |
| 长标题/标语溢出或拥挤 | 改用 `bottom-band`，左对齐、缩字号或分行；必要时先给用户 1–2 个缩短方案，不硬塞到框内 |

重试换输出文件名（`<style>-<location-name>-r1.png`、`<style>-<location-name>-r2.png`）保留对比，最终通过的改名/复制为 `<style>-<location-name>.png`。

## 两次重试仍不过

- 文字仍错 → 如实告诉用户一次性生图存在文字错误概率，建议：(a) 去掉非必要 tagline/微字；(b) 缩短到城市名与必要标签；(c) 用户同意后再继续尝试。不要擅自把目的地语言换成不符合规则的语言。
- 事实信息无法核验、参考图原有招牌无法可靠还原、标题仍不可读或几何仍不合格 → 不交付该图，说明具体失败项并询问用户是否修改输入/规则。
- 不要把错字图、虚构数据图、方向/边距不合格图当成品交付。
